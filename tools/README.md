# 因子体检工具（factor_health_check.py）

> 通用因子四项体检：**预测力 / 规模中性 / 换手成本 / 可成交性**。
> 依据：`funda-ml-mismatch` 项目实证（研究备忘录 2026-10-19）——仅剔除 1.1% 不可交易股即可吃掉 73% 的
> alpha，故任何因子入库前必须过这四关。对应 PM-Hub 决议 d3（naive IC 与可交易 IC 分开报告）。

## 用法

```powershell
# 最简：自动识别数值列（排除元数据），全量体检
python factor_health_check.py --panel <因子面板.parquet>

# 指定因子列 + 输出名
python factor_health_check.py --panel X.parquet --factors f1,f2 --out my_check

# 因子方向为"值越小越好"时翻转
python factor_health_check.py --panel X.parquet --factors f1 --flip

# 限定区间（如只看近十年）
python factor_health_check.py --panel X.parquet --start 2016-01
```

## 输入要求

- **必需**：`parquet` 或 `csv`，含 股票代码列 + 日期列 + 因子列
- **可选**：下月收益列（`ret_fwd`/`ret` 等）、市值列（`V`/`total_mv`）、行业列（`sw_industry`）
- 缺失的辅助列会**自动补齐**（从工作区行情/面板构建，首次构建后缓存于 `_aux/`）

## 四项体检与判定线

| # | 检验 | 指标 | 否决线 |
|---|---|---|---|
| ① | 预测力 | RankIC / IC_t / 十分位单调秩相关 | \|IC_t\| < 1.5 否决 |
| ② | 规模中性 | 逐月回归 `factor ~ log(V)` 取残差后重算 | 中性化后**符号反转** = size beta 否决 |
| ③ | 换手成本 | 月度换手 / 净收益 @10/20/30bp | 净@20bp ≤ 0 存疑 |
| ④ | 可成交性 | 剔除调仓日停牌/一字涨跌停后重算 | 衰减 > 50% 否决（alpha 在不可交易股） |

## 结论分级

- ✅ **强力**：IC_t≥3 且 中性化后 t≥2 且 可成交衰减 <30%
- ✅ **可用**：过基本关
- ⚠️ **存疑**：中性化后不显著 / 扣成本不赚钱
- ❌ **否决**：预测力不足 / size beta / 可成交衰减过大

## 输出

- `<out>.md`：体检报告（总览 + 逐因子明细 + 口径说明）
- `<out>.csv`：指标明细（可入库归档）
